Research Directions

研究可控的演化，而不只是更大的模型。

我们关注智能系统如何在明确边界、反馈与验证机制下持续演进，并以跨学科协作推动研究走向真实场景，探索金融领域的创新应用。

真实市场反馈多智能体博弈可验证演化

研究方向

推动决策系统由人工设计范式向自主进化范式演进

零界演化（SingularityX Evolution）致力于构建以 AI 自进化为核心的智能决策系统，并以金融市场这一高度非平稳、强对抗环境作为真实实验场。研究重点并不止于“更好的预测模型”，而是指向更本质的问题：智能体如何在动态环境中形成稳定决策能力，多智能体博弈中策略如何产生、竞争与进化，以及如何由“人类设计策略”进一步迈向“系统自主演化策略”。

系统框架

世界模型 + 多 Agent 博弈 + 强化学习 = 可自进化的智能决策系统

演化闭环

真实市场 + 模拟世界 + 自博弈筛选 = 策略的持续生成、竞争与进化

以金融市场为重要研究与应用场景，探索人工智能在金融研究、策略演化与风险管理中的创新应用，并以可复现的实验验证支撑持续改进。

核心研究问题

  • 如何使智能体在非平稳环境中形成稳定学习机制
  • 如何构建具备可收敛性的策略演化系统
  • 如何将博弈机制、强化学习与真实市场反馈有效连接

岗位特征

  • 工作对象并非标准化需求，而是尚未定型的核心问题
  • 需要在研究、工程实现与实验验证之间保持高频切换
  • 岗位定位并非流程执行，而是面向能够推动系统持续迭代的研究与工程人才

探索主题

从环境建模、策略生成到真实反馈闭环

当前研究正将原本分散的关键问题纳入统一系统验证，形成从环境建模、策略生成到真实反馈闭环的完整研究链路。

非平稳环境下的演化

  • 非平稳环境下的多 Agent 策略演化
  • 自博弈在开放系统中的稳定性问题
  • 强对抗环境中的策略生命周期管理

世界模型与决策系统

  • 金融市场中的世界模型构建方法
  • 从预测到决策：AI 系统的范式转变
  • 基于进化动力学的交易系统设计

AGENT FIRST / OPEN PARTICIPATION

把研究问题转化为开放任务

欢迎提出金融领域中有研究价值的问题，也欢迎提交有复现证据支持的相关解答。

了解开放参与

以 AI4S → RSI → AI4S 为研究路径，从金融智能决策出发，探索多智能体协作与自演化，构建贡献可验证、分配可解释的人机开放协同组织。
